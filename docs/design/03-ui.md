# 03｜界面重构

## 1. 信息架构

```
启动
 ├─ 首次引导：语言与主题 → 连接模型（api key / 订阅 / 本地模型） → 打开项目 → 默认权限
 └─ 修复模式（启动失败时出现，见12）
主窗口
 ├─ 左栏：项目与线程、等我处理、agent名册、任务看板、工作流
 ├─ 中间：线程（对话流+composer）
 ├─ 右栏：变更、文件、终端、预览、计划、子agent、轨迹
 └─ 顶栏：线程标题、引擎/模型/模式、worktree与分支、上下文占用、本线程花费、在外部ide打开、开pr
全局
 ├─ 命令面板（mac上是cmd+k，其他平台是ctrl+k）
 ├─ 通知中心与任务中心
 ├─ 用量面板
 └─ 设置
```

| 主窗口 | 见第3节 |

## 4. 关键交互

- **线程状态**：分运行中、待审批、待审阅、已完成、失败、排队中。状态显示在左栏徽标上，同时发系统通知。"等我处理"汇总所有待审批和待审阅的线程。
- **审批卡片**：
  - 显示线程名、工具、参数摘要和风险提示（越出工作区、联网、删除、执行脚本）。
  - 按钮有四个：允许一次、本会话允许、总是允许（写入规则，可选范围）、拒绝并说明。
  - 全程可以用键盘操作。
- **composer**：
  - @引用文件、符号、诊断、终端输出、其他线程、网址；/命令；拖放附件，粘贴图片。
  - 切换模式、模型、思考强度。
  - 消息可以排队，也可以在运行中插话。
  - 能编辑上一条重新发送，也能从任一轮分叉。
- **审阅**：
  - 按轮、按文件、按分支三种视图。
  - hunk级暂存和还原；行评论攒一批后交给agent。
  - 提交、开pr。
- **回滚**：在任一轮上可以"回到这里"（文件加对话，或只回文件），也可以"从这里分叉"。
- **长任务**：顶栏显示进度（goal状态、子agent数），任务可以转到后台，完成后通知。
- **错误提示**：错误归成可读的几类：额度用尽（附重置时间）、限速、上下文超长（建议压缩）、网络、认证。每类都给出下一步操作。
- **轨迹视图**：列出每一步的调用、参数、耗时、token和费用，用来排查"慢"和"贵"。
- **并排查看**：多个线程可以左右并排或网格排列，同时盯几个agent。
- **@agent下发**：在composer里@某个agent，把当前内容作为任务交给它，结果回到本线程（见06）。
- **浏览器标注**：在预览页面上圈选元素并写说明，作为下一轮的输入（对应codex的标注模式、cursor的design mode）。

## 5. 设计系统

- **令牌**：颜色（亮色和暗色）、字号、间距、圆角、阴影、动效时长；字体栈中文优先。
- **组件**：基于radix的自建组件库，包括按钮、输入、菜单、对话框、标签页、树、虚拟列表、代码块、diff视图、卡片、徽标、toast。
- **密度**：舒适和紧凑两档。
- **可访问性**：键盘全覆盖、焦点可见、屏幕阅读器标签、对比度达标。
- **快捷键**：全部可以自定义。常用的有新建线程、切换线程、发送、停止、审批允许或拒绝、命令面板。
- **国际化**：所有文案走i18next，默认简体中文，另有英文。
- **性能目标**（poc实测后再定）：
  - 冷启动到可交互小于2秒（m系列mac）
  - 1万条事件的线程滚动保持60fps
  - 空闲内存小于400mb
