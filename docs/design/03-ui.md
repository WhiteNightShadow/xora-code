# 03｜界面重构

## 1. 信息架构

```
启动
 ├─ 首次引导：语言与主题 → 连接模型（api key / 订阅 / 本地模型） → 打开项目 → 默认权限
 └─ 修复模式（启动失败时出现，见12）
主窗口
 ├─ 左栏：顶部“打开项目”（带“+”的文件夹）；搜索下面是三个跨项目的入口：总助手（统一入口，见06第23节）、团队（组织架构和团队任务两个页签，下面列进行中的运行，见06第24节）、工作流（同样）；然后是等我处理、项目与对话；每个项目一个“+”（新建对话、交给团队、新建工作流）
 ├─ 首页：有模型、有项目时是总助手（说要做什么，进行中的工作和以前的对话）；之前是首次引导
 ├─ 中间：线程（对话流+composer）
 ├─ 右栏：变更、文件、终端、预览、计划、子agent、轨迹
 └─ 顶栏：线程标题、项目与分支，⋯菜单里是右栏面板和线程操作。窗口没有系统标题栏，顶栏拖动窗口；没有顶栏的页面（总助手首页、团队页、成员页）最上面52像素的空白也能拖
全局
 ├─ 命令面板（mac上是cmd+k，其他平台是ctrl+k）
 ├─ 通知中心与任务中心
 ├─ 用量面板
 └─ 设置
```

## 4. 关键交互

- **线程状态**：分运行中、待审批、待审阅、已完成、失败、排队中。状态显示在左栏徽标上，同时发系统通知。"等我处理"汇总所有待审批和待审阅的线程。
- **审批卡片**：
  - 显示线程名、工具、参数摘要和风险提示（越出工作区、联网、删除、执行脚本）。
  - 按钮有四个：允许一次、本会话允许、总是允许（写入规则，可选范围）、拒绝并说明。
  - 全程可以用键盘操作。
- **composer**：
  - @引用文件、符号、诊断、终端输出、其他线程、网址；/命令；拖放附件，粘贴图片。
  - 下面一排切换模式、模型、思考强度。模式随时生效，运行中也用于接下来的操作，等着审批的调用按新模式重新判断；新线程默认用最后一次选的模式。
  - 右下角的圆环是上下文占用，点开看用量、压缩了几次、最近一次压缩前后的大小，也能立即压缩。对话里压缩的位置显示成一条分隔线，可以展开摘要。
  - **排队**（2026-11-04做上）：
    - 运行中回车或点排队按钮，消息排到输入框上方。这一轮自己结束后，排队的消息按顺序各开一轮。
    - 停止或出错后不会自动发出。排队的消息可以改、可以删，也可以点“现在发”：运行中就插进这一轮，没在运行就直接开一轮。
    - 只有用户自己开的对话能排队；团队、工作流和子agent的线程由宿主开轮。
    - 排队的消息存在线程里，应用重启后还在。
  - **编辑发出的消息**（2026-11-04做上）：
    - 鼠标移到消息上，旁边会出现铅笔。改完发出时，如果这一轮还在跑就先停掉，再回到这条消息之前（可以选择同时恢复文件），用改过的内容开新的一轮。
    - 图片附件没有保存，不会重发。
  - 也能从任一轮分叉。
- **审阅**：
  - 按轮、按文件、按分支三种视图。
  - hunk级暂存和还原；行评论攒一批后交给agent。
  - 提交、开pr。
- **回滚**：在任一轮上可以"回到这里"（文件加对话，或只回文件），也可以"从这里分叉"。这两个链接只在鼠标移到那一轮时出现；最后一轮不提供分叉（等于整条复制，11-01用户连点三次复制出三个一样的线程），压缩那一轮两个都不提供。
- **长任务**：顶栏显示进度（goal状态、子agent数），任务可以转到后台，完成后通知。
- **错误提示**：错误归成可读的几类：额度用尽（附重置时间）、限速、上下文超长（建议压缩）、网络、认证。每类都给出下一步操作。
- **轨迹视图**：列出每一步的调用、参数、耗时、token和费用，用来排查"慢"和"贵"。
- **并排查看**：多个线程可以左右并排或网格排列，同时盯几个agent。
- **@agent下发**：在composer里@某个agent，把当前内容作为任务交给它，结果回到本线程（见06）。
  - 2026-11-04起，@的候选里也有团队成员（不含主管），说明用界面语言显示。新建对话页和总助手首页的输入框也能@成员。
- **浏览器标注**：在预览页面上圈选元素并写说明，作为下一轮的输入（对应codex的标注模式、cursor的design mode）。

## 5. 设计系统

- **令牌**：颜色（亮色和暗色）、字号、间距、圆角、阴影、动效时长；字体栈中文优先。
- **组件**：基于radix的自建组件库，包括按钮、输入、菜单、对话框、标签页、树、虚拟列表、代码块、diff视图、卡片、徽标、toast。
- **密度**：舒适和紧凑两档。
- **可访问性**：键盘全覆盖、焦点可见、屏幕阅读器标签、对比度达标。
- **快捷键**：全部可以自定义。常用的有新建线程、切换线程、发送、停止、审批允许或拒绝、命令面板。
- **国际化**：中英文两套词典（见02）。
  - 界面语言默认跟随系统（2026-10-31用户定）：按系统首选语言的顺序，先遇到中文就用简体中文，先遇到英文或都不是就用英文。设置里可以固定成简体中文或English。
  - 外壳的菜单、托盘和对话框跟同一个设置走。修复模式不启动host，按系统语言显示。
  - host生成的文字也分两套：报错、运行说明、通知、审批卡片、交付报告，以及发给agent的提示。已经写下的记录保持写下时的语言。
- **性能目标**（poc实测后再定）：
  - 冷启动到可交互小于2秒（m系列mac）
  - 1万条事件的线程滚动保持60fps
  - 空闲内存小于400mb

## 6. 图标（2026-11-04）

用户反映图标“还是错版的”。排查结果：图标文件本身是对的，Finder按系统方式渲染出来，和计算器的底板大小、位置一致；错版出现在另外几个地方。
- 总助手首页顶部还是旧的紫色渐变闪光块，现在换成应用图标（`LogoMark`）。
- 菜单栏的托盘图标原来是把整块白色底板缩到16像素，在菜单栏里看起来像个白块。现在macOS用模板图`static/trayTemplate.png`（18和36像素，只有黑色图案），系统按浅色、深色菜单栏自动着色；windows和linux的托盘仍用`tray.png`。
- `icon.icns`里16、32像素的小图换成简化图：月亮线条更粗、星星更大，去掉16像素下看不见的连线和节点；64像素以上仍用完整图案。
- Dock会缓存图标：之前装的版本带着修正前的错位图标，装上新版后要重启Dock才会换掉。

这些都由`build/make-icons.ts`从`icon.svg`生成。另一个工具在build-resources里放了两张候选图（`icon-baiye-*.png`），没有采用，也没有提交。
