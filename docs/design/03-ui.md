# 03｜界面重构

## 1. 信息架构

```
启动
 ├─ 首次引导：语言与主题 → 连接模型（api key / 订阅 / 本地模型） → 打开项目 → 默认权限
 └─ 修复模式（启动失败时出现，见12）
主窗口
 ├─ 左栏：搜索下面是“成员”入口；项目与线程、等我处理；每个项目一个“+”（新建线程、交给团队、新建工作流），下面固定两行入口：团队看板在上（日常用得最多，有运行中的团队时显示个数），工作流看板在下
 ├─ 中间：线程（对话流+composer）
 ├─ 右栏：变更、文件、终端、预览、计划、子agent、轨迹
 └─ 顶栏：线程标题、项目与分支，⋯菜单里是右栏面板和线程操作。窗口没有系统标题栏，顶栏拖动窗口
全局
 ├─ 命令面板（mac上是cmd+k，其他平台是ctrl+k）
 ├─ 通知中心与任务中心
 ├─ 用量面板
 └─ 设置
```

## 2. 页面清单

| 页面 | 主要内容 |
|---|---|
| 首次引导 | 四步完成可用配置。模型可以先选本地或免费模型，跳过付费配置 |
| 主窗口 | 见第3节 |
| 新建线程 | 选项目、执行位置（本地或worktree）、场景模板或agent、引擎与模型；可以直接输入第一条消息 |
| agent名册与模板库 | 名册卡片显示每个agent的状态、当前任务、今日花费；模板分内置、已安装、市场三类，详情页显示用到的模型、工具、mcp、权限 |
| 成员 | 2026-11-02用户确认按grok bot的思路做（见06第19节）。侧栏“成员”进入，每个成员一张卡：头像、名字、角色·档位·权限、职责、记忆字数、例行任务数，可以直接派活或看详情。新建成员从内置成员改起：名字、职责、详细说明、模型档位、权限，用在所有项目或只在当前项目。详情页有派活、编辑、删除（内置成员是恢复默认），“在线程里@名字就能派活”的提示，可以展开的详细说明，记忆（它自己记的，能编辑、清空），例行任务（每天、工作日、每周一、每小时或cron，选项目、写要做的事，能开关、马上跑一次、看上次结果），最近的工作（对话、工作流、团队、例行，点开就是那个线程）。派活弹窗选项目、写任务，开一个它的线程。成员的线程在侧栏标题前有它的头像，线程顶部写着是谁，点一下回到成员页。2026-11-02加：“对话建人”（说要什么样的成员，组织助手问清楚、去github找skill让你挑、装之前每个都要你在卡片上同意，再建好成员，见06第21节）；编辑框里档位旁边能选模型；详情页显示它的skills；记忆可以切换看通用、各项目、团队共享三部分 |
| 团队看板 | 2026-11-02用户要团队入口和工作流一样明显。项目的团队运行：进行中在上（完成几项、几个成员在做、更新时间、花费），已结束在下，已归档的折叠在最后；右上角“新建团队任务”和“成员”。结束的运行可以归档（侧栏和看板不再列出，看板底部能展开）或删除（线程和没整合的worktree一起删，已经应用到项目里的改动不动），工作流运行同样可以归档、删除（子工作流运行和线程一起删，产出的文件不动） |
| 团队视图 | 名册（状态、当前任务、档位、今日花费、一次通过率）；看板（按状态分列、依赖连线，可以拖给agent或交给主管分配）；任务账本与进度账本的时间线；按档位和agent的花费、监督开销占比。任务卡上有阶段（第N阶段·剩M项）、主管最近一次指导、巡检提醒（06第20节）；对话页签里有阶段、指导、巡检三类记录；结束的运行顶部有归档、删除 |
| 工作流看板 | 项目的工作流列表（每个可以直接运行：输入、权限、预算；可以删除，删的是文件，运行记录保留，有没结束的运行时不让删）、新建工作流（描述流程，agent写成文件）、运行记录（每步的负责人、状态、产出、花费）。项目没被信任时，顶部说明原因并给出“信任这个项目”按钮，项目里的工作流在信任前不能运行，但不算文件有问题 |
| 工作流运行 | 顶部是状态、花费和预算、可随时改的权限，以及“需要你确认”（人工关卡、失败后跳不跳过、命令和各步骤线程里的审批，就地处理）。概览分层（2026-11-02用户定：像老板一样先看结果，过程要问的时候再看）：第一层是结论，运行结束后由旗舰档写给下任务的人，只有结论、问题、下一步三段，附产出的文件（就地预览或用默认应用打开），可以重新总结；运行中这里显示正在做什么、等你确认什么和进度。第二层是过程，运行结束后默认收起：执行流图（按依赖分列，连线和状态随运行变化，点一步跳过去）和每个环节一行结论，点开看这一步的全部输出。最下面是追问：开一个只读线程，带着这次运行的全部记录回答。另有看板（未开始、进行中、等你处理、完成、失败或跳过五列）和步骤明细（每一步的全部输出、时间线）两个页签 |
| 用量面板 | 今日、本月花费；按模型、厂商、项目、场景、子agent拆分；缓存命中率；订阅额度；预算 |
| 设置 | 通用、外观、模型与供应商、订阅、本地模型、路由与回退、提示词、权限与沙箱、扩展（skills、mcp、插件、hooks、命令）、引擎（外部agent）、用量与预算、更新与版本、隐私与数据、快捷键、实验功能 |
| 修复模式 | bootstrap内置的静态页面，不依赖应用包，功能见12 |

## 4. 关键交互

- **线程状态**：分运行中、待审批、待审阅、已完成、失败、排队中。状态显示在左栏徽标上，同时发系统通知。"等我处理"汇总所有待审批和待审阅的线程。
- **审批卡片**：
  - 显示线程名、工具、参数摘要和风险提示（越出工作区、联网、删除、执行脚本）。
  - 按钮有四个：允许一次、本会话允许、总是允许（写入规则，可选范围）、拒绝并说明。
  - 全程可以用键盘操作。
- **composer**：
  - @引用文件、符号、诊断、终端输出、其他线程、网址；/命令；拖放附件，粘贴图片。
  - 下面一排切换模式、模型、思考强度。模式随时生效，运行中也用于接下来的操作，等着审批的调用按新模式重新判断；新线程默认用最后一次选的模式。
  - 右下角的圆环是上下文占用，点开看用量、压缩了几次、最近一次压缩前后的大小，也能立即压缩。对话里压缩的位置显示成一条分隔线，可以展开摘要。
  - 消息可以排队，也可以在运行中插话。
  - 能编辑上一条重新发送，也能从任一轮分叉。
- **审阅**：
  - 按轮、按文件、按分支三种视图。
  - hunk级暂存和还原；行评论攒一批后交给agent。
  - 提交、开pr。
- **回滚**：在任一轮上可以"回到这里"（文件加对话，或只回文件），也可以"从这里分叉"。这两个链接只在鼠标移到那一轮时出现；最后一轮不提供分叉（等于整条复制，11-01用户连点三次复制出三个一样的线程），压缩那一轮两个都不提供。
- **长任务**：顶栏显示进度（goal状态、子agent数），任务可以转到后台，完成后通知。
- **错误提示**：错误归成可读的几类：额度用尽（附重置时间）、限速、上下文超长（建议压缩）、网络、认证。每类都给出下一步操作。
- **轨迹视图**：列出每一步的调用、参数、耗时、token和费用，用来排查"慢"和"贵"。
- **并排查看**：多个线程可以左右并排或网格排列，同时盯几个agent。
- **@agent下发**：在composer里@某个agent，把当前内容作为任务交给它，结果回到本线程（见06）。
- **浏览器标注**：在预览页面上圈选元素并写说明，作为下一轮的输入（对应codex的标注模式、cursor的design mode）。

## 5. 设计系统

- **令牌**：颜色（亮色和暗色）、字号、间距、圆角、阴影、动效时长；字体栈中文优先。
- **组件**：基于radix的自建组件库，包括按钮、输入、菜单、对话框、标签页、树、虚拟列表、代码块、diff视图、卡片、徽标、toast。
- **密度**：舒适和紧凑两档。
- **可访问性**：键盘全覆盖、焦点可见、屏幕阅读器标签、对比度达标。
- **快捷键**：全部可以自定义。常用的有新建线程、切换线程、发送、停止、审批允许或拒绝、命令面板。
- **国际化**：中英文两套词典（见02）。
  - 界面语言默认跟随系统（2026-10-31用户定）：按系统首选语言的顺序，先遇到中文就用简体中文，先遇到英文或都不是就用英文。设置里可以固定成简体中文或English。
  - 外壳的菜单、托盘和对话框跟同一个设置走。修复模式不启动host，按系统语言显示。
  - host生成的文字也分两套：报错、运行说明、通知、审批卡片、交付报告，以及发给agent的提示。已经写下的记录保持写下时的语言。
- **性能目标**（poc实测后再定）：
  - 冷启动到可交互小于2秒（m系列mac）
  - 1万条事件的线程滚动保持60fps
  - 空闲内存小于400mb
