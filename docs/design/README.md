# xora code 1.0重构设计

- 日期：2026-10-29起草，2026-10-30更新
- 状态：草案。
  - 已确认：
    - 计费只做用户自己的花费核算，xora本身不收费；
    - 在`next`分支开发，M1验收后合并回`main`；
    - 签名证书放到最后考虑。
  - 其余待决策见[14](14-cutover-roadmap.md#4-待决策)。
- 范围：在本仓库从零重写xora code，框架可以全部更换。旧版（theia+grok build，0.2.x）只作经验参考，代码不迁移。
- 依据：
  - 旧版源码审查；
  - grok build开源源码阅读；
  - 2026-10-29的业界与厂商调研。
  - 关键事实已回官方文档或源码核对；没核实的标"未核实"，工作量和性能标"估计"。

## 一页结论

1. **形态**：agent优先桌面，三平台一致。保留codex app、cursor 3 agents window、deepseek harness的核心能力和界面交互，逐项清单见[15](15-parity-advantages.md)。
2. **技术栈**：electron+react+vite+typescript，pnpm+turborepo单仓。不再用theia，也不再内置rust sidecar。
3. **分层**：bootstrap（冻结的极小启动器）→ ui（无状态）→ host（常驻，持有唯一状态，负责最终裁决）→ 引擎（acp子进程）→ 模型。
4. **引擎**：
   - 默认用xora engine：内核、acp服务端、工具、审批、子agent、压缩都是自研（原计划用pi做内核，实现时改了，见16）。
   - 外部agent经acp接入：codex、claude、kimi code、opencode、grok build、deepseek harness等。
5. **模型**：
   - api和订阅并行支持，按"厂商×通道×区域×协议"建模，协议怪癖做成数据。
   - 订阅分两类："key直连"和"官方agent代管"，合规优先。
6. **上下文**：提示词分四层；压缩分四级（裁剪工具输出→清理旧结果→摘要压缩→换模型压缩），并且照顾前缀缓存。
7. **扩展**：兼容agent skills、mcp（含远程oauth）、claude插件格式与市场、hooks；可以用对话生成skill、模板、工作流和插件。
8. **agent团队与工作流**（参考claude code agent teams、oh-my-openagent、magentic-one等）：
   - 给一个目标，旗舰档的主管负责拆分、派工、监督和验收，经济档的执行者做具体工作，最后整合交付。
   - 模型按旗舰、标准、经济、快速四个档位路由；做不了就升档；计划和交付由另一家族的模型评审。
   - 提示词分统一系统层、组织层、agent层，再加用户、项目、任务层。
   - 工作流把固定步骤串起来，带人工关卡、验收、定时与触发；某一步也可以交给主管动态编排。
   - agent在本机执行，每个agent都是独立的权限和预算边界，全程可审计。
9. **用量与成本**：只做用户自己的花费核算。
   - 从单次请求到项目，每一级都能看到花费。
   - 按厂商的阶梯价和峰谷规则计价，跟踪订阅额度，可以设预算。
   - 不急的任务可以排到空闲时段。
10. **更新与修复**：
    - 分四路独立更新：shell整包、应用包热更新、引擎、预设与扩展。
    - 启动时做健康检查，连续失败自动回滚；再不行退到内置基线，最后进修复模式。
11. **仓库**：在`next`分支开发，M1后合并回`main`。新代码从1.0.0-alpha起；三端在mac上交叉打包，虚拟机只做冒烟。
12. **节奏**：到1.0公测（M0～M6）一人加ai辅助约6～9个月（估计）。

## 设计原则

1. **host是唯一裁决者**：审批、路径边界、预算、更新时机都由host判断，ui只展示，引擎只执行。这是旧版api会话全放行留下的教训。
2. **引擎中立**：ui和存储不依赖某个具体引擎，引擎能力按acp `initialize`协商。
3. **只追加、可重建**：事件日志只追加，格式升级另写新文件；每次模型请求都能从日志重建。
4. **任何更新都可回滚**：代码、引擎、预设、扩展、数据都保留上一版和基线。
5. **怪癖是数据**：厂商差异写进预设，不写成代码分支。
6. **合规优先**：不伪装客户端，不代登录官方账号，订阅额度不做无人值守批跑。
7. **本地优先**：默认不上传任何数据，遥测和崩溃上报由用户开启。
8. **少原生依赖**：能用纯js就不用原生模块，保证三端都能在一台mac上出包。
9. **agent是边界**：每个agent的权限、工作目录、凭据和预算相互独立。
