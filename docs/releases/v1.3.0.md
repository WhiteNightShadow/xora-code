# Xora Code v1.3.0

1.3重做了上下文和记忆。长对话不再把前面的内容写成一段段摘要，而是整理成**任务状态**：发给agent的每句话原文保留，计划、定下的约束和决定、读过改过的文件、最近的命令和还没修好的失败都由引擎自己记着，模型只补它判断的部分；更早的工具输出遮成一行，带引用号，需要时原样取回。**记忆**从成员扩展到每段对话和总助手，多了一份所有对话和成员都读的“用户的偏好”，`recall`还能查同一个项目以前的对话。侧栏去掉了工作流入口，工作流交给总助手按需运行。

## 亮点

### 上下文：任务状态代替摘要

- 上下文快满时，前面的对话换成一份任务状态：发给agent的每条消息原文（最新的一条从不省略）、计划、约束（附原话）、决定（附理由）、事实、没解决的问题、走不通的路、读过改过的文件、最近的命令和其他工具调用、没修好的失败、后台任务，以及模型写的一段“做到哪了、下一步做什么”。大部分由引擎从记录里直接得来，不再是摘要的摘要。
- 对话里压缩的地方是一条分隔线，点“查看任务状态”看全文；`/compact`也整理成任务状态。
- 压缩请求和平时的请求用同一个前缀（同模型、同系统提示词、同工具），只在最后加一段要求，能命中缓存；模型没答或答得不对，就只用引擎的记录照样整理。
- 更早的工具输出在上下文到六成时一次性遮成一行（做了什么、成没成、多大、关键的一行），带引用号`#R123`；agent用新的只读工具`tool_output`按引用号原样取回，能分页、能搜。
- 新设置“工作上下文”（默认16万token）：模型窗口再大，用到这个量也会整理，长对话更快更省。系统提示词和工具定义也算在里面。
- 用62段真实的长对话回放：输入token少了约六成，最大的上下文从45.8万降到10.2万token，所有用户消息都在。

### 记忆：每段对话都有

- 记忆不再只属于成员：你自己的对话和总助手也能用`remember`和`recall`。
- 新加一份**用户的偏好**：所有成员和对话都会读；在成员面板的记忆里能看、能改、能清空。
- `recall`除了查笔记，还能查同一个项目里以前的对话（只读，不含当前这段，密钥会被遮掉）。
- 记忆在一段对话开始时取一份快照，之后每轮的系统提示词不变，缓存一直命中。
- 子agent、团队任务和工作流步骤不写用户的偏好：它们读的是网页和代码，不该当成你的偏好。
- 改写或清空记忆之前留一份`.bak`。

### 总助手

- “现在的情况”改为跟在你的每条消息后面，不再放在系统提示词里：系统提示词不变，缓存命中；只有最近3份报告带全文，其余用`work_status`查。

### 去掉了工作流入口

- 侧栏的“工作流”、工作流看板、项目“+”里的“新建工作流”、对话“⋯”里的“沉淀为工作流”都去掉了。
- 工作流本身还在：跟总助手说跑哪个，它用`workflow_start`跑项目里或数据目录`workflows/`里已有的工作流，跟进卡片打开运行页（结论、过程、看板、追问照旧）；总助手首页的“正在进行”也列出在跑的工作流。
- 信任项目在“设置→扩展”里。

### 修复

- 截断长文本时不会再把emoji这类字符切成两半。
- 成员记忆的说明写明分四部分（通用、用户的偏好、各项目、团队在项目里共享的）。

## 安装

| 系统 | 安装包 |
| --- | --- |
| macos（apple芯片） | `Xora.Code-1.3.0-mac-arm64.dmg`（或`.zip`） |
| macos（intel） | `Xora.Code-1.3.0-mac-x64.dmg`（或`.zip`） |
| windows x64 / arm64 | `Xora.Code-1.3.0-win-x64.exe` / `Xora.Code-1.3.0-win-arm64.exe` |
| linux x64 | `Xora.Code-1.3.0-linux-amd64.deb`或`Xora.Code-1.3.0-linux-x86_64.AppImage` |
| linux arm64 | `Xora.Code-1.3.0-linux-arm64.deb`或`Xora.Code-1.3.0-linux-arm64.AppImage` |

- 安装包没有apple developer id签名和公证，也没有windows authenticode签名。mac第一次打开被拦下时，到“系统设置→隐私与安全性”里点“仍要打开”；windows的smartscreen提示选“仍要运行”。
- 用release里的`SHA256SUMS`核对：`shasum -a 256 -c SHA256SUMS --ignore-missing`。
- linux推荐deb：ubuntu 24.04这类开启了apparmor限制的系统上，deb会装好沙箱需要的配置；AppImage在这些系统上会以`--no-sandbox`启动。

## 从1.2.0升级

- 直接装新版，数据目录不变，对话、成员、记忆和设置都保留；数据库还是第7版，不用迁移。
- 1.2.0压缩过的对话能接着聊：以前的摘要放进任务状态里“上次从头开始时做到哪了”一节，之后按新办法整理。
- 设置里多了“工作上下文”，默认16万；原来的“上下文上限”照旧生效。
- 成员原来的记忆不动；“用户的偏好”一开始是空的。
