# Xora Code v1.2.0

1.2把团队页做成了横向的组织树：组织下面还能分子组织，每个组织有自己的提示词和笔记，主管给成员做的每张卡打分。系统自带的人选都在**人才市场**里，能搜、能看提示词，聘进组织就能干活。总助手的对话不再属于某个项目，首页直接选模型和思考等级。干活的过程也更好跟：计划在输入框上方，跟着进度更新；思考时实时显示最新的内容。

## 亮点

### 组织树

- 团队页是一棵横着的树：最左边是你和总助手，往右是组织和子组织（最多三层），成员是组织里的一行。组织和成员都在弹窗里新建，不用开对话。
- 交给一个组织的团队任务，由离它最近的负责人带，子组织里的人一起干。负责人可以空着，由上一级的负责人带；一个主管可以带几个组织。
- 每个组织有自己的目录和提示词。成员干活时带着从最上层到它所在组织的这一串提示词，有冲突以靠后的为准；全体的提示词（`org.md`）也能在页面上改。
- 组织在每个项目里有自己的笔记：团队笔记记到干这件活的组织下面，`recall`能搜到所有组织的笔记。
- 点开成员只看名字、提示词、最近的项目、主管评分和token；记忆和例行任务在面板的“⋯”里。token按“新输入＋输出”算，缓存命中单独列出；有没定价的请求时，花费会标明不全。
- 团队任务写完汇报后，主管给每张卡打分：先按事实给基础分（做完没有、验收失败几次、升档、巡检），主管最多上下调10分并写理由，看不出来就不调并说明。成员面板在满3次后显示最近10次的平均分和走势。

### 人才市场

- 团队页的第三个页签，列出系统自带的全部人选：内置成员，加上只在模板里出现的前端工程师、运维工程师。能按名字、职责、提示词搜，按角色筛，能看完整的提示词。
- “聘用”把人选建进某个组织；已经在职的会标明在哪个组织，还能再聘一位；删掉的内置成员也在这里恢复。

### 总助手

- 对话不属于任何项目：首页不再选项目。它从你说的话、从这段对话已经派过的活里判断说的是哪个项目，判断不了就问你；只开了一个项目时就是那个。
- 首页和对话里一样，能选模型和思考等级，默认用设置里新对话的模型和思考等级。对话页不再显示项目、分支和权限模式，“⋯”里只留和它有关的面板和操作。
- 侧栏总助手下面列出最近的对话，能重命名、置顶、归档、删除；归档的对话在总助手首页“以前的对话”下面找回。

### 对话

- **计划**放在输入框上方：“计划 3/7 正在：xxx”，跟着agent的更新走，点开看整张清单；对话里每次更新计划是一行进度。agent连着10次工具调用都没更新计划时，会被提醒更新。
- **思考**时显示一个约十行高的窗口，跟着最新的内容往下走；在里面往上翻就停下，点开看全部。
- 新建对话能选思考等级，只列模型支持的档位。
- “等我处理”只列等着你的事：审批，和你自己的对话出错；做完的活不再列进来，对话行上照旧有审阅标记。
- 每段对话右上角的“⋯”里都能归档和删除。
- 所有确认都改成应用自己的弹窗，不会再被窗口挡住。
- 窗口的空白处（侧栏、组织树的画布、首页）都能拖动。

### 设置

- 全局提示词改成提示词目录：`<数据目录>/prompts/`里的每个md文件（子文件夹最多三层）是一个提示词，在“设置→提示词”里新建、修改、改名、删除、选用。1.1.0的`global.md`在你第一次选用之前照旧生效。

### 修复

- 下拉框的值为空时总显示“—”，盖住了“稍后再设”“按档位”这些选项的名字（13处）。
- windows上`rm -rf /usr/local`这类命令没有被认成大批量删除。

## 安装

| 系统 | 安装包 |
| --- | --- |
| macos（apple芯片） | `Xora.Code-1.2.0-mac-arm64.dmg`（或`.zip`） |
| macos（intel） | `Xora.Code-1.2.0-mac-x64.dmg`（或`.zip`） |
| windows x64 / arm64 | `Xora.Code-1.2.0-win-x64.exe` / `Xora.Code-1.2.0-win-arm64.exe` |
| linux x64 | `Xora.Code-1.2.0-linux-amd64.deb`或`Xora.Code-1.2.0-linux-x86_64.AppImage` |
| linux arm64 | `Xora.Code-1.2.0-linux-arm64.deb`或`Xora.Code-1.2.0-linux-arm64.AppImage` |

- 安装包没有apple developer id签名和公证，也没有windows authenticode签名。mac第一次打开被拦下时，到“系统设置→隐私与安全性”里点“仍要打开”；windows的smartscreen提示选“仍要运行”。
- 用release里的`SHA256SUMS`核对：`shasum -a 256 -c SHA256SUMS --ignore-missing`。
- linux推荐deb：ubuntu 24.04这类开启了apparmor限制的系统上，deb会装好沙箱需要的配置；AppImage在这些系统上会以`--no-sandbox`启动。

## 从1.1.0升级

- 直接装新版，数据目录不变，对话、成员、记忆和设置都保留。
- 第一次启动时数据库从第5版升到第7版（用量记录按成员归类），组织文件`groups.json`升到第2版，旧文件留一份`groups.v1.json`。1.1.0能打开升级后的数据，需要时可以装回1.1.0。
- 你的组织原样保留；一个主管带几个组织的照旧。

## 验证

每个安装包装好后跑更新演练（热更新、坏包回滚、修复模式共8项）和界面冒烟（60步，包括这一版新加的人才市场、计划、思考和总助手），再卸载检查残留。结果在出包验证后补上。
