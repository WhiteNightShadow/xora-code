# Xora Code v1.4.0

1.4把默认入口精简为Codex风格的**底部默认对话**（无需绑定项目即可直接开聊，侧边栏支持折叠收起），面向**OPC（一人公司 / 超级个体）**新增了一整套预设专家角色与一键团队模板，支持在输入框内直接选择或新建Agent角色；默认上下文拉满至主流模型的**100万token上限**，增强了记忆检索与提取，并集中修复了Windows端停止后重发失败、MiniMax自定义连接异常、三方中转站流式卡顿与修复模式校验自愈等问题。

## 亮点

### 默认对话与极简交互

- 去掉“总助手”标题与宣传说明，主界面默认就是驻留在底部的**默认对话**输入框：只要连好模型，不打开、不关联任何项目文件夹也能直接对话。
- 侧边栏顶部的**默认对话**支持像项目分组一样一键折叠/展开（折叠时显示对话数量与未读圆点，状态重启保留）。
- 去掉侧边栏与设置中的“用量”入口，精简回合底部统计与连接卡片细节，右侧面板在会话中随时保持可拖拽调宽。

### 面向OPC（一人公司）的角色体系与Agent选择器

- 对话输入框（含默认对话与项目新对话）内置**Agent角色选择器**：随时切换“默认对话”或任意角色直接开聊，菜单内可直接**新建Agent角色**（保存后自动在当前输入框选中）或打开角色库。
- 新增4套一键团队模板：**OPC一人公司全能班底**（业务统筹合伙人、独立产品经理、全栈独立开发、UI/UX与落地页设计师、增长与内容运营、市场与竞品分析师、自动化与数据专家、体验与质量验收官）、**OPC极简独立开发三人组**、**OPC内容与增长工作室**、**标准软件研发团队**。
- 新建角色弹窗顶部内置**自定义空白角色**（可选能力边界）与OPC预设标签，点击即可一键带入定位与系统提示词；单聊派活同样支持不关联项目。

### 100万token上下文、工具鲁棒性与记忆增强

- 默认上下文与工作上下文拉满至模型支持的最高窗口（主流模型默认约100万token，小窗口模型自动按真实上限裁剪；用到70%遮蔽旧工具输出，85%整理为任务状态）。
- 增强记忆索引检索（FTS5与相关性排序）及会话自动记忆沉淀；改进工具层模糊匹配、参数容错与大输出分页读取。

### Windows端专项修复与自定义模型体验升级

- **停止后再发消息失败**：取消运行中的轮次时自动补齐未闭合的工具调用结果并等待上一轮彻底收尾，Windows下调用完整路径`taskkill.exe`清理进程树并释放管道，不再留下导致下一条消息400报错的悬空`tool_calls`。
- **Windows端MiniMax与自定义模型接入**：自动探测并启用可用系统代理，同时自动剔除已关闭代理软件（如残留的本地端口环境变量）导致的死代理连接；优先走IPv4，按张校验证书库跳过异常证书，自动清理剪贴板不可见字符，并兼容MiniMax `/v1`与`/anthropic`双端点协议及请求头。
- **自定义模型接入精简**：精简为常见自定义接入类型（OpenAI兼容、Anthropic兼容、Gemini兼容、Ollama及主流官方直连），支持直接手填模型名即存即用，无需依赖中转站`/models`接口。
- **三方中转站防卡顿**：流式事件16ms合并投递 + 前端帧级批量渲染 + Markdown流式节流 + 超大模型列表搜索限流，高频小包中转站不再卡死界面。
- **修复模式自愈**：忽略系统生成的隐藏元数据文件（`.DS_Store`、`Thumbs.db`、`desktop.ini`），覆盖重装新版外壳时自动清除旧的内置基线校验失败记录。

## 安装

| 系统 | 安装包 |
| --- | --- |
| macos（apple芯片） | `Xora.Code-1.4.0-mac-arm64.dmg`（或`.zip`） |
| macos（intel） | `Xora.Code-1.4.0-mac-x64.dmg`（或`.zip`） |
| windows x64 / arm64 | `Xora.Code-1.4.0-win-x64.exe` / `Xora.Code-1.4.0-win-arm64.exe` |
| linux x64 | `Xora.Code-1.4.0-linux-amd64.deb`或`Xora.Code-1.4.0-linux-x86_64.AppImage` |
| linux arm64 | `Xora.Code-1.4.0-linux-arm64.deb`或`Xora.Code-1.4.0-linux-arm64.AppImage` |

- 安装包没有apple developer id签名和公证，也没有windows authenticode签名。mac第一次打开被拦下时，到“系统设置→隐私与安全性”里点“仍要打开”；windows的smartscreen提示选“仍要运行”。
- 用release里的`SHA256SUMS`核对：`shasum -a 256 -c SHA256SUMS --ignore-missing`。
- linux推荐deb：ubuntu 24.04这类开启了apparmor限制的系统上，deb会装好沙箱需要的配置；AppImage在这些系统上会以`--no-sandbox`启动。

## 从1.3.0升级

- 直接安装新版覆盖即可，数据目录不变，历史对话、团队角色、记忆和连接设置全部保留。
