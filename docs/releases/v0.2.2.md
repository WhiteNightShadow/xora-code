# Xora Code v0.2.2 Preview

> **Alpha / Prerelease**：这是未经平台商业签名的公开预览版，用于体验、测试和反馈，不建议用于生产环境或高风险项目。

Xora Code 是一个开源的 Grok 桌面应用与 Grok Build GUI 客户端。它将项目树、代码编辑器、终端、流式 Agent 对话、Plan、工具活动、Diff 审阅、Skills 和 MCP 管理放进同一个跨平台桌面工作区。

![Xora Code 工作区](https://raw.githubusercontent.com/WhiteNightShadow/xora-code/v0.2.2/docs/images/xora-code-workspace.png)

## 本版重点

- **统一 Skills / MCP 配置**：Grok 订阅、自定义模型、新会话、历史恢复和 Provider 切换使用同一份 Xora 配置，不再因为独立 Grok Home 丢失扩展。
- **真实会话加载状态**：MCP 管理页区分“已发现、诊断正常、当前会话已加载”；只有当前会话真正加载的 MCP 才会进入 Agent 快捷菜单。
- **运行期同步**：MCP 变化优先热更新当前 Runtime；旧 Runtime 不支持时安全重启并恢复会话，绝不自动重放 Prompt。Skills 支持运行期 reload。
- **更稳定的空闲资源占用**：MCP 生命周期查询增加语义去重、前沿合并、冷却、single-flight 和会话定向刷新，减少重复全量扫描与空闲 CPU 抖动。
- **自定义模型改进**：新建兼容服务默认使用 OpenAI Responses、500K 上下文窗口和服务端联网搜索；获取模型后可直接快速选择，也可继续手工输入模型 ID。
- **权限语义统一**：请求审批 / 完全访问在所有项目、会话、窗口和应用重启间保持一致；完全访问解除 Xora Code 的工作区路径限制，但不会绕过操作系统权限和 Grok Build 自身策略。
- **跨平台桌面包**：补齐 macOS Apple Silicon、macOS Intel、Windows x64 与 Linux x64 安装包，统一内嵌 Grok Build `0.2.102`。

## 签名与安装提示

- **macOS**：应用仅使用 ad-hoc 签名，没有 Developer ID，也没有 notarization，Gatekeeper 可能拦截首次启动。
- **Windows**：安装包没有 Authenticode 产品签名，SmartScreen 可能显示未知发布者提示。
- **Linux**：提供 SHA-256 校验和，没有 GPG detached signature。

本项目由社区独立维护，不是 xAI 官方客户端，与 xAI 不存在隶属、赞助或背书关系。“Grok”与“Grok Build”仅用于准确描述上游集成与互操作能力。
