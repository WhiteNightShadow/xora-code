# Xora Code v0.2.9

本版修复桌面端无法及时更新 Grok CLI 的问题：可在 Agent 设置的“运行时与更新”中检查并安装 xAI 官方稳定版，无需等待桌面端重新发版。

## 更新内容

- 接入 xAI 官方 npm 分发源，按操作系统和架构获取原生 CLI，显示当前版本与最新可用版本。下载验证 SHA-512，并在独立临时目录验证精确版本及 ACP 初始化，不运行 npm 安装脚本。
- 更新通过后切换空闲 Agent；有执行中任务时阻止激活。安装失败保留当前组件，可重试，也可回滚到上一版本或内置基线。
- 修复 Windows 首次升级时备份内置 CLI 返回 `EPERM` 的问题；失败时清理临时副本，避免残留文件影响重试。
- 修复 Windows 更新锁竞争，保留旧客户端仍在使用的锁，避免多个窗口或进程同时替换 CLI。
- 兼容 Grok 1.x 的项目信任要求，在用户已信任的项目中保持 Skills/MCP 发现；Provider 切换后继续共享配置，保留思考等级选择和保存行为。

## 安装与验证

提供 macOS Apple Silicon DMG、Windows x64 EXE、Linux x64 AppImage 和 deb 四个安装文件。附件只保留安装文件，SHA-256 列于 GitHub Release 正文；构建来源、依赖清单和测试报告留档。本版未提供 macOS Intel 安装包。

内置 Grok CLI `0.2.102` 用于回退；已验证可从桌面端升级到官方 `1.0.50`，完成回滚、再次升级及重启。Mac、Linux、Windows 均执行完整测试和每端 24 项界面回归，覆盖 Provider 切换、思考等级、共享 Skills/MCP、流式响应与加密凭据恢复。流式测试使用真实 CLI 与隔离的本地测试 API。

本版为社区正式版。macOS 使用 ad-hoc 签名，未做 Apple Developer ID 签名和公证；Windows 未做 Authenticode 签名；Linux 未提供 GPG 签名。桌面应用本体仍需手动覆盖安装，官方 CLI 更新不等同于 Xora 签名自动更新。

## 已知限制

- 打包后的文件搜索此前存在 ASAR 内 `rg` 路径导致的 `spawn ENOTDIR`，本轮未修复。
- 思考等级原生弹出菜单的键盘导航未自动化；首次点击焦点、可用选项和实际选择保存已覆盖。
