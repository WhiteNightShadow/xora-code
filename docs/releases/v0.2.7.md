# Xora Code v0.2.7

> **Stable / Production**：`v0.2.7` 是面向 Windows 会话恢复、消息可靠性与工作区边界的稳定性修复版本。它由同一份已提交源码分别在 macOS、Windows 与 Linux 原生环境构建，继续内嵌并校验 Grok Build `0.2.102`。

Xora Code 是一款开源的 Grok 桌面应用与 Grok Build GUI 客户端。它将项目树、代码编辑器、终端、流式 Agent 对话、计划、工具活动、Diff 审阅、权限控制、Skills 和 MCP 管理放进同一个跨平台桌面工作区。

## 本版修复

### 消息发送与会话恢复

- 区分“本地已排队”和“后端已接收”：任务尚未取得正式接收确认时，消息不会从对话中静默消失，也不会让同一个标签回落到欢迎页。
- Runtime、IPC 或 Provider 上下文在发送期间发生变化时，原始文字会保留在对应会话，界面提供可理解的恢复或重试状态；Xora Code 仍不会自动重放执行状态不明确的任务。
- 历史首次读取、ACP hydration 或运行时恢复失败时保留已经可见的本地内容，不再先清屏后留下空白会话。
- sidecar stdout 提前结束会被立即视为运行时故障；活动任务结算后只恢复 Runtime 和会话身份，不重新发送旧 Prompt。

### Windows 任务所有权与删除

- sidecar 崩溃与会话索引竞争同时发生时，任务终态重试会跨过 30 秒锁租约；若存储仍不可用，会保留任务所有权并给出恢复提示，待存储恢复后由加载、取消或删除安全结算。
- 本窗口拥有但已经失去活动句柄的任务可安全结算；其他 Xora Code 窗口仍在执行的任务继续严格拒绝抢占或删除。
- 会话删除由后端按真实所有权判断。用户可以对本窗口任务执行“取消并删除”，不会再因陈旧的前端 `running` 状态永久失去删除入口。
- 标签页的关闭按钮仍只关闭标签，不删除本地历史；真正删除继续通过历史列表或会话右键菜单完成。

### 历史权威与错误降噪

- 一次瞬时空快照不再被解释为永久删除；后续完整快照可以恢复会话和历史。只有显式删除或明确的 `SESSION_NOT_FOUND` 才会建立删除墓碑。
- 同一次 Runtime 断流产生的 `PROMPT_FAILED`、ACP EOF 与 `SIDECAR_CRASHED` 重复诊断会合并为一条中文恢复提示，保留诊断代码但不再连续刷屏。
- 崩溃状态优先于陈旧的会话 `running` 元数据，顶部状态、停止按钮和恢复提示保持一致。

### 工作区文件边界

- 多根工作区中所有已信任目录都可用于 Agent 文件变更，不再只承认第一个根目录。
- 工作区内以 `..` 开头的合法文件名（例如 `..hidden`）不再被误判为路径穿越。
- 工作区外路径和穿出信任根的符号链接仍按权限模式拒绝；重复的无效 Diff 只显示一次可操作提示。

## 兼容性与升级

- Provider、模型与思考等级、Grok Home、Skills/MCP 配置和本地 JSONL 会话历史保持兼容，不执行破坏性数据迁移。
- Grok Build sidecar 继续固定为 `0.2.102`；本版修复位于 Xora Code 的 Electron 会话、持久化和工作区安全边界。
- Windows 升级前请完全退出所有旧版 Xora Code 窗口，并在任务管理器确认没有残留的 Xora Code 或 `grok.exe` 进程，再运行 `v0.2.7` 安装包。
- 如果旧版曾遗留执行中的会话，`v0.2.7` 会先按任务所有权安全结算；它不会为了恢复界面而自动重放历史任务。

## 验证范围

- 无接收确认、IPC 断流、Provider/工作区切换、sidecar EOF/退出和 Runtime 单次恢复。
- Windows 索引锁耗尽、同 owner orphan claim、foreign claim、取消并删除及显式删除不复活。
- 历史读取失败、瞬时空快照、完整快照恢复、重复错误归并和同一标签不回欢迎页。
- 主根/附加根、`..hidden`、工作区外路径、符号链接越界和重复 Diff 降噪。
- TypeScript 全仓构建、Agent / Fake ACP / 产品外壳测试，以及三端安装包的版本、架构、sidecar、插件、notices、SBOM 和摘要校验。

## 签名与安装提示

- **macOS**：当前使用 ad-hoc 签名，没有 Apple Developer ID，也没有 notarization，Gatekeeper 可能拦截首次启动。
- **Windows**：当前没有 Authenticode 产品签名，SmartScreen 可能显示未知发布者。
- **Linux**：提供 SHA-256 校验和，尚未提供 GPG detached signature。
- **自动更新**：签名更新信任锚尚未配置，因此本版本不会声称已启用正式自动更新；应用与官网更新失败不会影响现有本地功能。

本项目由社区独立维护，不是 xAI 官方客户端，与 xAI 不存在隶属、赞助或背书关系。“Grok”与“Grok Build”仅用于准确描述上游集成与互操作能力。
